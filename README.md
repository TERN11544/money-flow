# Money Flow

เว็บบันทึกรายรับรายจ่ายและติดตาม subscription ส่วนตัว รองรับภาษาไทย มือถือ และคอมพิวเตอร์

## สิ่งที่ทำได้

- เพิ่ม แก้ไข ค้นหา และกรองรายการรายรับ/รายจ่าย
- ดูยอดคงเหลือ รายรับ รายจ่าย และสัดส่วนรายจ่ายตามหมวดหมู่
- เพิ่มและติดตาม subscription รายเดือนหรือรายปี พร้อมวันตัดรอบถัดไป
- ปรับธีมสว่าง/มืด และปรับเลย์เอาต์ให้เหมาะกับจอหรือการซูม

## ความเป็นส่วนตัว

เวอร์ชันนี้บันทึกข้อมูลไว้ใน Local Storage ของเบราว์เซอร์เท่านั้น จึงไม่มีรายการทางการเงินถูกส่งขึ้น GitHub หรือเซิร์ฟเวอร์ ข้อมูลจะยังไม่ซิงก์ข้ามอุปกรณ์จนกว่าจะเพิ่มระบบคลาวด์ในเฟสถัดไป

## การเปิดใช้งาน

เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์แบบ static หรือ GitHub Pages ได้ทันที โดยไม่ต้องติดตั้ง dependency ใด ๆ
