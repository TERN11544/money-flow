# Money Flow

เว็บบันทึกรายรับรายจ่ายและติดตาม subscription ส่วนตัว รองรับภาษาไทย มือถือ และคอมพิวเตอร์

## สิ่งที่ทำได้

- เพิ่ม แก้ไข ค้นหา และกรองรายการรายรับ/รายจ่าย
- ดูยอดคงเหลือ รายรับ รายจ่าย และสัดส่วนรายจ่ายตามหมวดหมู่
- เพิ่มและติดตาม subscription รายเดือนหรือรายปี พร้อมวันตัดรอบถัดไป
- ปรับธีมสว่าง/มืด และปรับเลย์เอาต์ให้เหมาะกับจอหรือการซูม

## ความเป็นส่วนตัว

ข้อมูลจะอยู่ใน Local Storage ของเบราว์เซอร์เสมอ และจะถูกส่งไปยัง Supabase เฉพาะเมื่อผู้ใช้ตั้งค่าโปรเจกต์และเข้าสู่ระบบแล้ว ตารางคลาวด์มี Row Level Security จำกัดให้บัญชีที่เข้าสู่ระบบอ่าน/เขียนเฉพาะแถวของตนเอง

ห้ามใส่ `secret` หรือ `service_role` key ในเว็บหรือ GitHub ให้ใช้เฉพาะ `sb_publishable_...` key ซึ่งออกแบบมาสำหรับแอปฝั่งเบราว์เซอร์ และต้องเปิดใช้ RLS ตาม SQL ด้านล่าง

## เปิดใช้การซิงก์ข้ามอุปกรณ์

1. สร้างโปรเจกต์ Supabase และเปิด SQL Editor
2. วางและรันไฟล์ `supabase-setup.sql` เพื่อสร้างตารางและนโยบายสิทธิ์
3. ใน Supabase ตั้งค่า Auth URL Configuration ให้ Site URL เป็น `https://tern11544.github.io/money-flow/` เพื่อให้อีเมลยืนยันกลับมาที่เว็บนี้
4. คัดลอก Project URL และ Publishable key จากหน้า Connect/Settings ของโปรเจกต์ แล้วใส่ใน `supabase-config.js` (`url` และ `publishableKey`)
5. เผยแพร่ไฟล์ที่ตั้งค่าแล้ว จากนั้นเปิดเมนู “ซิงก์” ในเว็บเพื่อสร้างบัญชีและเข้าสู่ระบบ

เมื่อเข้าสู่ระบบจากอุปกรณ์แรก ระบบจะถามก่อนว่าจะอัปโหลดข้อมูลในเครื่องหรือใช้ข้อมูลจากคลาวด์ หากเลือกอีกฝั่ง ข้อมูลที่ถูกแทนจะถูกสำรองไว้ใน Local Storage ของอุปกรณ์นั้นก่อน อุปกรณ์อื่นเพียงตั้งค่าโปรเจกต์เดียวกันและเข้าสู่ระบบบัญชีเดียวกัน ข้อมูลจะโหลดจากคลาวด์เมื่อเปิดเว็บ และตรวจการเปลี่ยนแปลงเป็นระยะขณะหน้าเว็บเปิดอยู่

ถ้าสมัครแล้วระบบต้องยืนยันอีเมล ให้กดลิงก์ในอีเมลก่อน แล้วจึงกลับมาเข้าสู่ระบบ การซิงก์ต้องใช้อินเทอร์เน็ต; หากออฟไลน์ ข้อมูลยังคงบันทึกบนอุปกรณ์และรอซิงก์เมื่อกลับมาออนไลน์

## การเปิดใช้งาน

เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์แบบ static หรือ GitHub Pages ได้ โดยไม่ต้องติดตั้ง dependency ใด ๆ หากยังไม่ตั้งค่า Supabase แอปยังใช้แบบ Local Storage บนอุปกรณ์เดียวได้ตามเดิม
